# English Video Shadowing App

Local-first PWA for practising English videos sentence by sentence.

## First version

- Open a local video without uploading it
- Import SRT or WebVTT subtitles
- Normal playback, sentence-by-sentence pause and single-sentence loop
- Previous, next and repeat sentence controls
- English/bilingual/hidden subtitle modes
- Select which sentences require shadowing
- Edit timestamps, speaker labels and subtitle text
- Save preferences and learning progress on the device

The app is static and can be deployed directly to GitHub Pages.
